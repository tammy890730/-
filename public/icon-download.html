拾頁・透明版桌面圖示

保留綠色圓角，四角沒有白底。

下載透明版圖示（ZIP）

下載檔案約 93 KB，內含 Windows 圖示與使用說明。

若按下後沒有看到下載提示，請按 Ctrl＋J 查看瀏覽器的下載清單。也可以對上方按鈕按滑鼠右鍵，選「另存連結為…」。

套用到 Windows 桌面

  1. 在「下載」資料夾找到 ZIP，按右鍵選「全部解壓縮」。
  2. 對桌面的拾頁捷徑按右鍵，選「內容」。
  3. 按「變更圖示」→「瀏覽」，選擇解壓縮後的 shiye-green-transparent.ico。
  4. 按「確定」及「套用」。

替換捷徑圖示不會變更你的文獻、PDF 或筆記。
