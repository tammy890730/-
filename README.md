# 拾頁 SHIYE · 文獻管理與比較

繁體中文的個人研究書桌。React 19、TypeScript、Vite；以 IndexedDB 儲存文獻、筆記、比較及 PDF Blob。JSZip 提供完整備份，無後端或外部 API，字型使用系統字型。

## 開啟

需要 Node.js 22 以上（目前環境使用 24）。

```sh
cd /workspace/-
npm ci
npm run dev -- --port 5173
```

開啟 Vite 輸出的網站位址。雲端使用時須由執行平台提供連接埠存取；本專案不會自行公開部署。固定使用同一網址與連接埠，避免建立不同的瀏覽器資料庫。

```sh
npm run build                 # 型別檢查與正式建置，輸出 dist/
npm run preview -- --port 5173 # 檢視正式建置
npm test                      # Chromium 端對端測試
```

測試使用 npm 的 `@sparticuz/chromium`，目前設定適用 Linux x64 執行環境；不另下載 Playwright 瀏覽器。若在其他作業系統開發，需修改 `playwright.config.ts` 使用當地支援的 Playwright 瀏覽器。

## 使用

1. 按「新增文獻」填寫資訊，必填文獻名稱，其餘可留白。閱讀狀態、重要性與進度可直接在表格修改。
2. 點文獻名稱或「開啟筆記」，開啟原文及筆記。上傳 PDF 後可預覽、下載、更換或移除。九個筆記區塊輸入後自動儲存；原文摘錄獨立標示，應補頁碼。
3. 勾選至少兩篇文獻，按「建立比較」。也可直接按「新增比較」後選擇文獻。比較可新增多筆、修改及刪除，文獻連結可回到原文。
4. 右上角或筆記顯示「已儲存」後才關閉頁面。儲存失敗會保留當前文字，顯示錯誤並提供重試；可先匯出備份救回資料。
5. 「備份與還原」→「匯出完整備份」下載 ZIP。還原時選 ZIP，選擇合併或取代。取代會再次確認。合併依識別碼去重，相同識別碼以備份為準，保留其他資料。
6. CSV 匯出全部文獻（不受目前篩選影響），含摘要、設計與發現；不含筆記、比較與 PDF。Excel 公式起始字元會加上單引號避免被當成公式。

## 資料實際保存位置與限制

- 資料在**使用者目前瀏覽器、目前網站來源的 IndexedDB `shiye-literature`**，object store `library` 的 `current` 鍵。PDF 存成 Blob，並非 localStorage，也不在雲端專案目錄內。
- 重新整理、重開相同瀏覽器與相同網站後仍在。不同裝置、瀏覽器、使用者設定檔、網址、協定或連接埠不會共用資料。無登入、雲端同步或多人協作。
- 請一次只用一個分頁編輯；不同分頁同時編輯可能覆蓋彼此資料。切換分頁前等儲存完成，重新載入後再編輯。
- IndexedDB 是瀏覽器管理的本機儲存，不是永久保管服務。清除網站資料、無痕模式、瀏覽器或系統清理都可能移除資料。**請定期匯出完整備份至其他儲存位置**。
- 單一 PDF 上限 100 MB，完整 ZIP 還原上限 512 MB；實際容量依瀏覽器磁碟配額而定。大型備份需足夠記憶體。還原僅供信任的拾頁備份。
- PDF 以瀏覽器內建閱讀器顯示；若不支援嵌入，請另開原文或下載。無 PDF 標記、OCR、AI 摘要與自動擷取。
- 文獻總表所有欄位皆隨水平捲軸移動，沒有固定欄位；文獻較多時可在表格內上下捲動。
- 刪除文獻會提示被引用的比較數；刪除其 PDF、筆記與關聯，關聯少於兩篇的比較也會刪除。沒有復原功能，刪除前請備份。
- 初始資料庫為空。可自行載入明確標記的虛構示例，並一鍵清除；所有示例不可用作學術引用。

## 備份格式

ZIP 包含 `library.json`（`format: shiye`、`version: 1`、文獻與比較）以及 `pdfs/<文獻識別碼>.pdf`。筆記在各文獻的 `notes` 欄位。還原會先檢查欄位、重複識別碼、比較關聯與 PDF，驗證成功後才更新資料庫；資料庫以單一交易寫入，避免部分還原。

## 驗證範圍

`tests/workflow.spec.ts` 以真正 Chromium 驗證：新增與編輯、上傳 PDF、自動儲存筆記、建立比較、重新載入及新分頁讀取、匯出備份、刪除關聯、取代還原、PDF 位元組一致、合併去重、搜尋／年份篩選／排序、CSV、虛構示例清除、無效備份與手機操作。測試資料只存在測試瀏覽器。

## 桌面 App 與版本更新

已加入 PWA 安裝資訊、192/512 圖示、離線程式快取及更新提示。**尚未發布到正式網址，不能把本機驗證視為已提供可安裝的線上 App。**

發布後，以 Chrome 或 Edge 開啟固定 HTTPS 網址，按「安裝到桌面」或網址列安裝圖示。Safari 可使用「加入 Dock」。是否出現原生安裝選項仍由瀏覽器與作業系統決定。第一次開啟需連線，程式快取成功後可離線使用。

打開 App 或回到前景會檢查新版；開啟期間每分鐘也會檢查。新版下載後提示「儲存後更新」，使用者按下後重開新版。正在編輯文獻／比較表單、還原備份或筆記未儲存時，更新按鈕停用。更新不清除 IndexedDB，因此同一網址、同一瀏覽器的文獻與 PDF 會保留。這是**程式版本更新**，沒有跨裝置資料同步。

原先下載的「拾頁.html」無法自行連上聊天或接收新版。切換到網站前，請先在舊版匯出完整備份，首次開啟網站後再還原。
